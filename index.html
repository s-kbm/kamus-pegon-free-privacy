Kebijakan Privasi

pegon lite (Kamus Pegon) — com.ahmadsadam.aksarapegonfree

Terakhir diperbarui: Oktober 2026

pegon lite (Kamus Pegon) adalah aplikasi gratis yang didukung iklan (AdMob), tanpa gerbang pembelian apa pun. Kebijakan ini menjelaskan data apa saja yang diproses aplikasi, dan bagaimana cara kerja fiturnya.

1. Cara Kerja Fitur Alih Tulis

Aplikasi ini wajib online. Teks yang Anda ketik (Latin ↔ Pegon, termasuk fitur Latihan Menulis) dikirim ke server kami (Cloudflare Workers) untuk diproses, karena kamus dan mesin alih tulis berjalan di server, bukan di perangkat Anda. Kami tidak menyimpan alamat IP Anda di log atau basis data kami, dan tidak menyimpan teks yang Anda kirim setelah diproses. Sebagai penyedia infrastruktur, Cloudflare memproses alamat IP dan data teknis koneksi agar permintaan dapat disampaikan (lihat Kebijakan Privasi Cloudflare).

  • Riwayat dan favorit alih tulis Anda tetap disimpan secara lokal di perangkat Anda saja (localStorage), tidak pernah dikirim atau disimpan di server kami.
  • Karena mesin alih tulis berjalan di server, aplikasi tidak berfungsi tanpa koneksi internet.

2. Iklan (Google AdMob)

Aplikasi ini menampilkan iklan banner dan iklan sela (interstitial) lewat Google AdMob. AdMob dapat mengumpulkan pengenal perangkat (mis. Advertising ID) dan data teknis lain untuk menampilkan serta mengukur iklan, sesuai Kebijakan Privasi Google dan ketentuan AdMob. Kami sendiri tidak mengakses atau menyimpan data yang dikumpulkan AdMob.

3. Rate Limiting

Karena endpoint alih tulis kami bersifat publik (tanpa akun/login), kami menerapkan batas jumlah permintaan per menit (berdasarkan alamat IP dan sesi) untuk mencegah penyalahgunaan. Penghitungan ini bersifat sementara, tidak disimpan sebagai riwayat, dan tidak dipakai untuk mengidentifikasi Anda.

4. Verifikasi Keaslian Aplikasi (Google Play Integrity)

Agar layanan server hanya dipakai oleh aplikasi asli yang dipasang lewat Google Play, aplikasi meminta token integritas dari Google Play Services di perangkat Anda, lalu mengirimkannya ke server kami. Server kami meminta Google memverifikasi token tersebut (apakah aplikasinya asli, dipasang dari Google Play, dan perangkatnya lolos pemeriksaan integritas). Pemrosesan di sisi Google tunduk pada Kebijakan Privasi Google.

  • Hasil verifikasi hanya dipakai untuk menerbitkan sesi sementara (berlaku sekitar 2 jam) yang disimpan di perangkat Anda.
  • Kami tidak memakai token atau hasil verifikasi ini untuk melacak atau mengidentifikasi Anda, dan tidak menyimpannya di server kami.
  • Jika verifikasi gagal (misalnya aplikasi tidak dipasang dari Google Play), server tidak akan melayani permintaan alih tulis.

5. Izin Aplikasi

Aplikasi meminta izin akses internet dan izin melihat status jaringan, yang digunakan untuk: (a) memproses alih tulis dan verifikasi keaslian aplikasi lewat server kami, (b) menampilkan iklan lewat AdMob, dan (c) menampilkan indikator online/offline. Tidak ada izin sensitif lain (kamera, lokasi presisi, kontak, mikrofon, dll) yang diminta atau digunakan.

6. Data yang TIDAK Kami Kumpulkan

Aplikasi ini tidak mewajibkan pembuatan akun atau login, dan kami sendiri tidak mengumpulkan: nama, email, nomor telepon, kontak, lokasi presisi (GPS), foto/media, atau data biometrik apa pun dari pengguna. Data yang diproses pihak ketiga (AdMob dan Google Play Integrity) dijelaskan di bagian 2 dan 4.

7. Anak-anak

Aplikasi ini tidak ditujukan khusus untuk anak di bawah 13 tahun dan tidak dirancang untuk menarik anak-anak secara khusus. Kami tidak sengaja mengumpulkan data pribadi dari anak-anak.

8. Keamanan Data

Seluruh komunikasi antara aplikasi dan server kami (alih tulis, pembaruan) menggunakan koneksi terenkripsi (HTTPS).

9. Perubahan Kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu. Perubahan signifikan akan diumumkan melalui pembaruan aplikasi atau catatan rilis di Play Store.
